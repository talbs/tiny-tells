# Code of Conduct

Tiny Tells follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good intent, and keep critique on the work, not the person.

## Reporting

Report anything that breaks it privately through [GitHub's private reporting form](https://github.com/talbs/tiny-tells/security/advisories/new). The form is labeled for security issues, but it's the only private channel to the maintainer, so use it for conduct reports too. Only the maintainer can see what you send.

If someone breaks GitHub's own rules, you can also [report them to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
